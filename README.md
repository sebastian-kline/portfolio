# Sebastian Kline Portfolio

Personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion.

The site showcases my software engineering projects, technical experience, and background as a junior software engineer.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion

## Features

- Responsive modern UI
- Animated particle background
- Smooth section animations
- Project showcase section
- Work experience and about sections
- Resume download
- Contact links
- Automatic redirect for invalid routes

## Projects Featured

### TrackHire
Production-style full-stack job application tracker built with:
- Java
- Spring Boot
- React
- JWT Authentication
- PostgreSQL
- Supabase
- Railway
- Vercel

### Internal Company Portal
Role-based company portal with:
- Employee / Manager / Admin roles
- JWT authentication
- Spring Security
- PTO workflows

### IT Support Ticket System
Backend-focused CRUD support ticket system with:
- REST APIs
- Validation
- Layered architecture
- Ticket lifecycle management

## Running Locally

Clone the repository:

```bash
git clone https://github.com/sebastian-kline/YOUR-REPO.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Deployment

This portfolio is deployed using Vercel.
